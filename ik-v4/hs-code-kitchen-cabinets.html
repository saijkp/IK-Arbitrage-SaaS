HS Code for Kitchen Cabinets: UK Codes and Duty

Wooden kitchen cabinets sit within heading 9403, under kitchen furniture subheading 9403 40. The checked UK Global Tariff lists 2% third-country duty for fitted wooden kitchen units and other wooden kitchen furniture; confirm the full code for your exact goods before shipping.

Which UK commodity code covers kitchen cabinets?

Heading 9403 covers other furniture and its parts. Within it, 9403 40 covers wooden furniture of a kind used in the kitchen. The UK tariff distinguishes fitted kitchen units from other wooden kitchen furniture. Metal cabinets, separately supplied components and mixed-material goods need their own classification check.

The table uses HMRC's UK Global Tariff reference document, version 1.34, effective 1 October 2026. These are standard third-country (most favoured nation) duty rates, not a delivered-cost quotation. Some entries are eight-digit tariff lines rather than full import declaration codes: use the live tool and your broker to select the complete code and check all measures for China and the shipment date.

Full import lines for fitted wooden kitchen units are 9403 40 10 10 (hand-made) and 9403 40 10 90 (other); for other wooden kitchen furniture they are 9403 40 90 10 (hand-made) and 9403 40 90 90 (other). The reference document gives 2% at each of the two parent tariff lines. Do not infer hand-made status from a supplier's marketing description.

Worktops, sinks, taps and appliances need separate detail

A kitchen quotation can contain several classifications. For a worktop, record whether it is timber, natural stone, engineered stone or another material, its composition, and how it has been cut or finished. For sinks, record the material; the stainless-steel rate above does not establish the rate for ceramic or composite sinks. For taps, identify whether they are mixing valves.

For appliances, give the broker each model's function and specification. For loose handles and hinges, specify the material and use. A cabinet code is not a universal code for everything travelling with a kitchen. The correct line and duty depend on the exact product: use the UK Trade Tariff lookup where a figure is not given here.

How to prepare a kitchen import brief

  • Send the cabinet schedule, drawings, quantities and photographs, including carcass and door materials.
  • Separate worktops, sanitary fittings, hardware and appliances on the product list.
  • Ask the broker to confirm classification using the goods as they will actually be presented for import.
  • Keep the agreed descriptions consistent across the quotation, invoice and packing list.

Frequently asked questions

What is the HS code for wooden kitchen cabinets?

Start with heading 9403 and subheading 9403 40 for wooden kitchen furniture. Fitted units use UK tariff line 9403 40 10; other wooden kitchen furniture uses 9403 40 90. Ask your broker to confirm the full import code for the exact goods.

What is the UK import duty on wooden kitchen cabinets from China?

The checked UK Global Tariff reference document lists a 2% third-country duty rate for both fitted wooden kitchen units and other wooden kitchen furniture. Confirm the complete code and all applicable measures in the live tariff before shipping.

Can I use the cabinet code for the whole kitchen order?

Do not assume one code covers the order. Give your broker separate details for worktops, sinks, taps, appliances and loose hardware so each product can be classified correctly.

Does IK ENG show duty and import VAT on the quotation?

Yes. Duty and import VAT are shown on the quotation. The customer is the legal importer, and customs clearance is arranged through an authorised UK broker.
